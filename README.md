# 📊 Expense Tracker - Frontend (React.js + Vite)

A modern, responsive financial dashboard built with **React.js (Vite)**, **Axios**, and **Vanilla CSS**.

## 🌟 Features
- Add, Edit, Delete expenses with live total updates
- Category filtering (`Food`, `Travel`, `Shopping`, `Other`)
- Interactive spending breakdown meters
- Confirmation dialogs for deletion
- Inline field-level validation and 3-second auto-dismissing toast notifications
- Indian Rupee currency formatting (`₹`)

## 🚀 Running Locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the Vite development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:5173](http://localhost:5173) in your browser.
